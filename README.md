# 🎮 2D Arcade Games Collection | C++, SFML

Developed a collection of 16 classic 2D arcade games using C++ and SFML, implementing game loops, collision detection, sprite rendering, event handling, animations, and object-oriented design principles
## Games Included

- Arkanoid
- Doodle Jump
- Chess
- Snake
- Tetris
- Asteroids
- Xonix
- Mahjong Solitaire
- NetWalk
- Bejeweled
- Racing

## Technologies

- C++
- SFML 3
- Object-Oriented Programming
- Game Loop
- Collision Detection
- Sprite Animation

## How to Build

```bash
g++ -std=c++20 main.cpp -o game.exe \
-lsfml-graphics \
-lsfml-window \
-lsfml-system
