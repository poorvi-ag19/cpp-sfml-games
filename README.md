# 🎮 16 Games in C++ using SFML

A collection of classic 2D games developed using **C++** and **SFML**.

## Games Included

- Arkanoid
- Doodle Jump
- Chess
- Snake
- Tetris
- Asteroids
- Xonix
- Mahjong Solitaire
- NetWalk
- Bejeweled
- Racing

## Technologies

- C++
- SFML 3
- Object-Oriented Programming
- Game Loop
- Collision Detection
- Sprite Animation

## How to Build

```bash
g++ -std=c++20 main.cpp -o game.exe \
-lsfml-graphics \
-lsfml-window \
-lsfml-system
